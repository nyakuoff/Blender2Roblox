# What's New in v0.4.0 (Pre-alpha)

**Headline:** Blender animations land in Roblox Studio frame-exact, with no skipped or invented frames, and baking is 10–100× faster than the previous plugin.

> Pre-alpha: core import works, and feedback is very welcome. Expect rough edges.

## Features
- **Frame-exact export**: every scene frame is sampled once and nothing lands between frames, so playback matches Blender.
- **Exact (every frame) toggle**:
  - Off: keeps only the keys needed to stay within 0.001 studs / 0.1° of Blender.
  - On: keeps every frame where anything moves.
- **Stepped animation stays stepped**: Constant keys export with Roblox Constant easing.
- **Skinned meshes**: coats, hair and capes animate as Roblox Bones, and are rescaled automatically if the mesh was imported at a different size.
- **Rigs with several characters**: one armature holding R15, R6 and props puts each bone on the right part. Select several rigs in Studio to import onto all of them at once.
- **Studio panel, docked left**:
  - Live progress bar.
  - Timeline you can drag to scrub.
  - Play/Pause, plus a Stop that always works, even mid-loop.
  - Loop that applies right away.
  - Publish to Roblox.
- **Send rig to Blender**: builds an armature with the rig's real meshes, UVs and welded accessories.
- **Clear import report**: lists Studio joints that got no animation, and separately counts bones that belong to other rigs in the same armature.

## Improvements
- Baking only evaluates what the armature depends on. A 35-second coat animation now bakes in 1.2 s (Exact) / 1.7 s (reduced), down from 2.8 s / 4.3 s.
- Key reduction is about 4× faster.
- Exact mode skips frames where nothing moves, with identical playback: up to 20× fewer keys to transfer and build in Studio.
- The import status shows where time goes: Blender + transfer, decode, and keyframe build.

## Install
1. **Blender 4.2+:** *Edit → Preferences → Get Extensions → ⌄ → Install from Disk* → `blender2roblox-0.4.0.zip`.
2. **Roblox Studio:** *Plugins tab → Plugins Folder* → drop in `Blender2Roblox.rbxm` (or `.rbxmx`), then restart Studio.

If you used an earlier build, remove the old "Roblox Link" extension and the old `BlenderLink` plugin file first.

## Known limitations
- Send rig only reads meshes you or Roblox own; others arrive as boxes. Textures aren't sent yet.
- No live auto-sync, and no Roblox → Blender animation import yet.
